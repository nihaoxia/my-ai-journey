## 快速排序

数组排序
- 冒泡 两两相邻位置
- 选择排序 选择最小的元素放到最前面
- 快速排序 从左到右，将当前元素插入到已排序的元素中
- 插入排序 从左到右，将当前元素插入到已排序的元素中
O（n^2）

 - 递归 对左边和右边的数组分别再做

 快排(quick sort) 是一种基于**分治策略**的排序算法，运行高效
 (nlogn) (平均情况)  应用广泛
 分而治之
 ## 递归，分治的区别
 递归是代码实现方式（函数自身调用）
 自顶向下 缩小问题的规模
 分治是算法思想，绝大多数用递归思想实现
 分 + 治 + 合 三部
 分 将大问题切成互相独立的小问题
 治 解决小问题
 合 合并小问题的结果
