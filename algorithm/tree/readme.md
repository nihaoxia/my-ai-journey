## 定义
- 它可以没有根节点，作为一棵空树存在
- 如果不是空树，那么必须由根节点、左子树和右子树组成，且左右子树都是二叉树。

## 树的关键概念
- 树的层次计算
    根节点所在的那一层第一层，其子节点在第二层，以此类推
- 树的高度
    叶子节点高度记为一，每向上一层高度加一，一直到目标节点，即为目标节点的高度
- 度的概念
    一个节点开叉出去多少个子树
- 叶子节点
    度为0的节点。最后一层都是叶子节点
- 树的深度
    根节点到叶子节点的路径长度，即为树的深度

二叉树不可以简单定义为每个节点的度为2的树
左右子树的位置是严格约定，不能交换

## 树的遍历
### 递归
一定是先左后右
- 前序遍历
    先访问根节点，再递归遍历左子树，最后递归遍历右子树
- 中序遍历
    先递归遍历左子树，再访问根节点，最后递归遍历右子树
- 后序遍历
    先递归遍历左子树，再递归遍历右子树，最后访问根节点
### 迭代
队列
- 层序遍历
    从根节点开始，按层遍历，先访问根节点，再访问左子树，最后访问右子树
