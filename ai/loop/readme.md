# AI Loop

## Loop 循环
一条推文迎来了700万人参观
别再给AI写提示词，而应该去设计一个loop
Claude code 作者也说 不写prompt 而是loop

- loop 是计算机最底层的能力之一
loop包含三件事
 - 从哪开始，重复做什么，什么时候停
 一万行的数据，要逐行检查，改格式
 人工完成要做很久，写程序循环

 我们现在在用的所有LLM都是loop跑出来的
 Deepseek,Claude,Qwen
 训练的底层都是一个逻辑

 拿一批数据给模型看，算它错了多少，
 调整参数，再来一轮。
 万亿次循环之后，AI就学会了对话和协作。

 每天和AI一问一答的过程
 写prompt，看结果，不满意，再改，
 再来
 手动，AI协作
 工作交给了AI，但是得盯着AI干活
 Loop 可以把我们抽离出来
 - completion
 - check
 循环往复 跟最终的目标 退出

优势是 解放了人，
