## 思考
AI 工作流也能干活 它和Agent 有什么区别？
很多人会混淆 反正都是AI在执行任务

## Agent 智能体
和 workflow 逻辑完全不一样，它不走在一条预设的轨迹上，而是站在一个开放的空间里，而是自己去探索怎么做(智能)。从技术上 一个Agent往往具备三个大的核心能力

第一个能力：感知环境
  通过输入文本、图像、数据来理解任务，有哪些工具可以调用 当前情况如何 如何分步骤 如何规划
第二个能力：规划路径
  不是预先定义好 而是动态去生成任务链
第三个能力：执行任务
  去调用工具 完成子任务 并不断去调整

## 举例
你让Agent 去规划旅游 它可能会去搜一下机票和酒店价格 再去查天气和签证需求。然后结合你的偏好和预算 动态去权衡方案
整个过程 它可能走的路径和你的预期完全不同 这就是Agent 的关键区别 自主性和适应性 它不会被一个固定流程限制 而是像一个思考中的个体。所以本质区别在于：Workflow是确定地执行 Agent 是一个不确定的探索。 Workflow 就好像一条高速公路 路线很清晰很固定 效率很高 但能到达既定的终点
Agent 更像一个司机 他知道要去哪 但可以随时去改道(修路等意外情况，感知环境) 尝试新的路线 甚至在目的地发生变化的时候 自行调整

所以 从产业角度 workflow更适合流程化 重复性的任务
比如审批流程 数据清洗 客服AI
Agent 更适合动态的角色场景 比如: 复杂搜索 策略规划

从技术栈的领域 workflow更依赖于规则 图形化编排 (coze)  流程引擎 Agent更依赖于大模型的推理能力和记忆能力 包括它的工具调用等

未来我们的AI 工程将会集合Agent 和 workflow 的双重能力
底层是workflow 提供稳定性和可控性  上层是Agent 提供灵活性和智能性

workflow是骨架 Agent 是workflow的大脑
workflow的缺点是没什么创造性 Agent有，但是有时候不太可控 不可预测 一起结合 即高效又有智慧
