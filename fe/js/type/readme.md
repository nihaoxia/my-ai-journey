# js有哪些数据类型
八种数据类型
根据ECMA262规定
primitive 原始数据类型有6种，其中
numeric(新增) 细分为 number和bigint
还有一种对象

## 简单数据类型，
   原始数据类型（primitive types） 
   - Number 数值类型
   - String 字符串类型
   - Boolean 布尔值
   - Null 空值
     - 表示某处应该有个值，不过当前没有值（空的值）
     - 用于一个有意设置为空的对象引用 （空的引用）
     - 可以用于清空一个变量的值，释放内存，垃圾回收
   - Undefined 未定义值
      表示未初始化或不存在的变量值
      - 当申明一个变量但未赋值时
      - 某个对象的属性不存在
      - 函数没有返回值时
      - 访问不存在的数组索引
## es6之前js只有6种类型
   - Symbol 符号值
   - BigInt 大整数
## 复杂数据类型
   引用数据类型(内存分配)

## 内存分配去思考
- 冯诺依曼
  计算机由运算器、控制器、存储器、输入输出
- 代码 外存 硬盘
- 编译，代码从硬盘调入内存中
- 执行上下文  变量环境，词法环境，执行代码
- 推入**调用栈** 就在栈内存中
   快，空间小
   变量环境/词法环境  原始数据类型，写入值
   引用数据类型，也在栈内存之中，存的是对象的地址
   编译阶段给他的空间正好合适  
   函数执行上下文对象占用多少空间是算得出来的
   当一个函数执行完，出栈，很快的算出新的栈顶元素位置
   指针偏移量就可以切换上下文的执行
   快速、稳定、扩展
