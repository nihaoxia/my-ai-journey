# 一、项目基础定位

## 1. 项目名称

**遗境千年**

## 2. 赛道定位

**生活娱乐赛道**

理由：
- 项目不是纯知识学习平台，也不是单纯文化展览。
- 目标是让用户在娱乐、创作、模拟经营、互动体验中接触非遗。
- 强调“可看、可玩、可收藏、可分享、可复玩”。

## 3. 产品当前方向

《遗境千年》是一款面向大众用户的非遗数字体验产品。

用户以现代人的身份，从现代科技生活场景进入“遗境”，在探索不同非遗主题后，解锁对应的衍生玩法，将现代生活素材转化为非遗作品，并收藏进个人图鉴。

当前核心表达：

> 用户不是被教育“非遗很重要”，而是在生活化、娱乐化、创作型玩法中发现：非遗也可以成为今天生活里的表达方式、游戏方式、创作方式和社交分享内容。

# 二、开场设定与叙事方向

## 1. 开场名称

**百艺入屏**

## 2. 核心主题

> 从古代夜市的百艺娱乐，到现代手机里的非遗数字体验。

开场不批判现代科技，也不表达“现代不好”。它强调的是：

> 非遗不是停在古代，而是一路流转到今天，并以数字娱乐、创作工具和作品社区的方式进入现代人的手机生活。

## 3. 开场动画结构

```text
古代夜市总览
↓
火艺 / 打铁花
↓
傩面巡游
↓
皮影开幕
↓
剪纸飞纹
↓
糖人凝形
↓
五艺汇流
↓
现代手机定格
↓
屏幕出现《遗境千年》入口
```

## 4. 分镜设计

### 镜头 1：古代夜市总览

画面：
- 夜市长街。
- 灯笼成排。
- 小摊、人群、叫卖声。
- 远处鼓点和锣声。

文案：

> 千年前，百艺入市，灯火照夜。

### 镜头 2：火艺 / 打铁花

画面：
- 火艺人吐火，火焰冲天。
- 远处打铁花火星如雨。
- 火光照亮人群。

定位：
- 吐火作为开场视觉钩子。
- 打铁花仍是正式火艺核心玩法。
- 吐火归入火艺奇观意象，不单独作为五个主题之一。

### 镜头 3：傩面巡游

画面：
- 傩面舞者从火光后出现。
- 面具呈朱红、黑金纹路。
- 鼓点变重。
- 舞者踏步，地面纹样亮起。

### 镜头 4：皮影开幕

画面：
- 傩纹转为影灯。
- 皮影幕布亮起。
- 影偶人物从幕布两侧入场。
- 少年、动物或神兽剪影短暂闪现。

### 镜头 5：剪纸飞纹

画面：
- 红纸展开。
- 剪刀落下。
- 云纹、花鸟、窗花、福字轮廓飞散。
- 纸纹与皮影线条交织。

### 镜头 6：糖人凝形

画面：
- 铜勺倾糖。
- 金色糖线在石板上流动。
- 糖线勾勒出兔子、龙、花灯等形状。
- 小孩接过糖人。

### 镜头 7：五艺汇流

画面：
五种元素共同汇流：
- 火星。
- 傩纹。
- 影线。
- 纸纹。
- 糖线。

它们汇成一道数字光流。

### 镜头 8：现代手机定格

画面：
- 镜头从光流中拉远。
- 现代夜晚室内 / 宿舍 / 家中。
- 桌上或手中一部手机亮起。
- 手机屏幕中出现《遗境千年》的入口。

手机屏幕文案建议：

```text
遗境千年
千年百艺，今入指尖

进入
```

## 5. 开场文案

开头：

> 千年前，百艺入市，灯火照夜。

结尾：

> 千年后，百艺入屏，指尖重生。

## 6. 动画时长

建议控制在 **30～35 秒**。

| 镜头 | 时间 |
|---|---:|
| 古代夜市总览 | 4 秒 |
| 火艺 | 5 秒 |
| 傩面 | 4 秒 |
| 皮影 | 4 秒 |
| 剪纸 | 4 秒 |
| 糖人 | 4 秒 |
| 五艺汇流 | 4 秒 |
| 现代手机 | 4 秒 |
| 合计 | 33 秒 |

## 7. 叙事原则

- 避免说教。
- 避免“现代科技不好、传统文化更好”的对立表达。
- 强调传统文化与现代生活可以互相连接。
- 非遗不是过去的标本，而是可以被今天重新体验、再创作、再传播的生活内容。
- 古代夜市对应过去的生活娱乐，现代手机对应今天的生活娱乐。

## 8. 第一版实现建议

第一版不一定制作完整视频，可采用：
- 分镜插画。
- 视差滚动。
- 火星粒子。
- 图案淡入。
- 镜头推拉。
- CSS / Canvas 动画。

# 三、首页第一屏：古今共屏

## 1. 首页核心概念

**古今共屏**

首页不是普通 App 首页，也不是纯古风星图，而是一张可以横向轻滑的“古今长卷”。

核心表达：

> 左承千年百艺，右接现代指尖。

首页视觉上呈现：

```text
古代百艺场景
↓ 自然流动
现代数字平台
```

古代和现代不做生硬分割，而是通过火星、云气、剪纸纹、皮影线、糖线和数字光点自然过渡。

## 2. 横向轻滑

用户可以左右滑动首页：

- 向左看更多古代百艺氛围。
- 向右看更多现代功能内容。

但视觉上保持同一张画卷，不做割裂式分屏。

### 左侧：古代风格

承接开场动画里的古代夜市。

元素：
- 灯笼。
- 古街。
- 火星。
- 影幕。
- 傩面纹样。
- 剪纸纹。
- 糖线。
- 人群剪影。
- 卷轴 / 长街 / 云气。

作用：
- 营造文化氛围。
- 显示五艺源头。
- 承接“千年前，百艺入市”。

### 右侧：现代风格

右侧不是冷冰冰的科技风，而是“现代手机数字平台 + 国风 UI”。

元素：
- 今日推荐。
- 每日任务。
- 万象集作品流。
- 我的图鉴。
- 创作按钮。
- 数字光点。
- 半透明卡片。

作用：
- 告诉用户这是可以玩的产品。
- 提供入口、任务、作品社区和成长进度。
- 承接“千年后，百艺入屏”。

## 3. 五艺入口悬浮在古今之间

五艺入口不完全放在左边，也不完全放在右边。

它们放在古代氛围和现代功能的过渡区域，代表：

> 从传统文化转化为现代玩法的桥。

五艺入口对应当前确定的非遗大类，而不是随意命名。

| 首页入口 | 对应非遗 | 衍生玩法 |
|---|---|---|
| 岁时民俗 | 打铁花 | 铁花造景 |
| 民俗仪式 | 傩戏 / 傩舞 | 傩面行仪 |
| 表演叙事 | 皮影戏 | 一幕生影 · 影戏工坊 |
| 民间美术 | 剪纸 | 一物成剪 |
| 饮食游艺 | 糖人 / 糖画 | 糖摊小铺 |

入口展示建议：

```text
岁时民俗
打铁花 · 铁花造景

民俗仪式
傩面 · 傩面行仪

表演叙事
皮影 · 影戏工坊

民间美术
剪纸 · 一物成剪

饮食游艺
糖画 · 糖摊小铺
```

## 4. 首页信息结构

第一屏只放核心内容，避免信息过载。

```text
左侧：古代百艺长卷
  - 灯火、火星、傩面、影幕、剪纸、糖线

中间：遗境千年标题
  - 千年百艺，今入指尖

过渡区：五艺入口
  - 岁时民俗
  - 民俗仪式
  - 表演叙事
  - 民间美术
  - 饮食游艺

右侧：现代数字平台界面
  - 今日推荐
  - 每日任务
  - 万象集精选
  - 我的图鉴进度
```

## 5. 今日推荐

首页应突出一个“今日推荐玩法”，降低用户选择成本。

示例：

```text
今日推荐
岁时民俗 · 铁花造景
挑战：生成一次“火树银花”
奖励：焰火纹样碎片
```

或：

```text
今日推荐
饮食游艺 · 糖摊小铺
节日订单：制作一盏“元宵灯兔”糖画
奖励：限定灯纹
```

## 6. 视觉原则

不要做：

```text
左边古代 | 右边现代
```

而要做：

```text
古代夜市元素逐渐变成现代数字界面
```

推荐视觉关键词：
- 古今共屏。
- 数字长卷。
- 国风 UI。
- 灯火入屏。
- 云气过渡。
- 金色光流。
- 青绿底色。
- 暖金火光。
- 半透明卡片。

统一色系建议：
- 青绿。
- 暖金。
- 米白。
- 墨色。
- 朱红点缀。

## 7. 风险与控制

### 风险 1：首页信息过多

解决：第一屏只放标题、今日推荐、五艺入口、图鉴 / 万象集 / 任务入口。

### 风险 2：古代与现代割裂

解决：不用硬边界，用同一套色系、纹样和光流连接。

### 风险 3：五艺入口只显示大类，用户不知道里面是什么

解决：大类下面必须显示具体非遗与玩法名称。

# 四、非遗大类设计

原本曾考虑“传统生活美学类”，但该分类概括性过强，后续调整为更具体、更适合生活娱乐赛道的分类。

## 当前建议大类

| 大类 | 含义 | 对应主题/玩法方向 |
|---|---|---|
| 岁时民俗类 | 节日、庆典、祈福、民俗活动 | 打铁花、灯彩、节庆活动 |
| 民俗仪式类 | 祈愿、驱祟、祭仪、面具仪式 | 傩戏、傩舞、傩面祈愿 |
| 表演叙事类 | 戏曲、说唱、影戏、民间表演 | 皮影戏、AI 小剧场 |
| 民间美术类 | 剪纸、年画、纹样、面塑等 | 剪纸、生活照片转剪纸 |
| 饮食游艺类 | 可吃、可玩、可摆摊、可经营的民俗技艺 | 糖人、糖画、糖摊经营 |

## 分类目标

分类不是为了做百科，而是为了帮助用户理解：

- 非遗不只是一种“古老文化”。
- 它分布在节庆、仪式、表演、美术、饮食、游艺等生活场景中。
- 每一类都可以转化为适合现代用户体验的玩法。

# 四、五个核心非遗主题

当前确定将原来的“陶艺 / 瓷器”替换为“糖人 / 糖画”，因为糖人 / 糖画更生活化、更娱乐化，也更适合做模拟经营和复玩机制。

## 当前五个主题

| 非遗主题 | 所属大类 | 核心基础体验 | 解锁后的衍生玩法 |
|---|---|---|---|
| 打铁花 | 岁时民俗类 | 了解节庆火艺、工具、源起与安全性 | 铁花造景 |
| 傩戏 / 傩舞 | 民俗仪式类 | 认识傩面、仪式、舞步与祈愿 | 傩仪编阵 / 傩面祈愿 |
| 皮影戏 | 表演叙事类 | 体验一折传统皮影小戏 | AI 皮影小剧场 |
| 剪纸 | 民间美术类 | 理解剪纸寓意、纹样与技法 | 生活照片转剪纸 |
| 糖人 / 糖画 | 饮食游艺类 | 认识糖画工具、熬糖、走线技艺 | 糖摊模拟经营 |

# 五、核心产品循环

当前产品核心不再只是“看展 + 收集信物”，而是：

```text
首页五艺入口
↓
进入某个非遗剧情篇章
↓
多节点剧情选择
↓
在剧情中体验非遗工具、流程、技艺和文化寓意
↓
不同选择触发不同后续选项、文化碎片和体验方式
↓
获得分支结局
↓
收藏结局图鉴
↓
获得对应信物
↓
解锁该非遗的深度创作玩法
↓
进行创作 / 经营 / 演出 / 造景
↓
生成个人非遗作品
↓
收藏进图鉴
↓
发布到万象集或继续复玩
```

核心主玩法正式确定为：

> **多分支剧情体验 + 结局收集 + 节点回溯**

用户点击任意非遗后，会进入该非遗的剧情篇章。剧情由多个选择节点组成，每个节点提供 3～5 个选项，不同选择会影响后续可见选项、非遗体验方式、文化碎片、信物属性、深度玩法素材与最终结局。首次进入需完整体验剧情，二次进入后可跳过已看剧情，直接跳至选择节点或从关键节点重开，以便收集不同结局。

## 剧情节点结构

每个非遗剧情篇章由多个节点组成：

```text
开场节点
↓
选择节点 A
↓
分支节点 B / C / D
↓
非遗体验节点
↓
选择节点 E
↓
分支节点 F / G
↓
结局节点
```

## 第一版控制范围

| 项目 | 第一版 |
|---|---|
| 每个非遗剧情节点 | 4～5 个 |
| 每个节点选项 | 3～4 个 |
| 每个非遗结局 | 5～8 个 |
| 隐藏选项 | 每个非遗 1～2 个 |
| 节点回溯 | 支持从关键节点重开 |
| 跳过机制 | 二次进入可跳过已看剧情 |

完整版可扩展为：
- 每个非遗 6～8 个关键选择节点。
- 每个节点 3～5 个选项。
- 每个非遗 10～15 个结局。
- 更多跨玩法隐藏选项。

## 选择影响对象

每个选择不能只是换一句台词，至少影响以下一种或多种内容：

| 影响对象 | 说明 |
|---|---|
| 后续选项 | 解锁或隐藏某些分支 |
| 剧情走向 | 进入不同事件 |
| 非遗体验方式 | 采用不同工具、技法、流程 |
| 角色关系 | 与剧情人物关系变化 |
| 文化碎片 | 解锁不同知识点 |
| 结局类型 | 影响最终结局 |
| 信物属性 | 获得不同风格的信物 |
| 深度玩法素材 | 解锁不同模板、纹样、参数、角色 |

## 剧情变量

为避免剧情分支指数级膨胀，引入隐藏变量记录用户选择倾向。

通用变量示例：

```text
技艺理解
情感倾向
传承倾向
创新倾向
```

不同选择会改变变量。

示例：
- 选择遵循老匠人建议 → 技艺理解 +1。
- 选择帮孩子完成愿望 → 情感倾向 +1。
- 选择保留传统流程 → 传承倾向 +1。
- 选择尝试新方式 → 创新倾向 +1。

最终根据变量组合决定结局、信物属性和解锁素材。

## 跳过与回溯机制

### 首次进入

用户完整体验：

```text
剧情开场
↓
文化引入
↓
选择节点
↓
非遗体验
↓
结局
```

### 二次进入

用户可以选择：

```text
继续完整体验
或
跳至已看过节点
或
直接进入选择节点
或
从某个分支点重开
```

## 故事回溯

为了方便收集结局，加入“故事回溯”。

用户在结局图鉴中可以看到：

```text
已解锁结局：3 / 8
未解锁结局：5
可从关键节点重开
```

示例：
- 从“选择祈愿”重开。
- 从“选择工具”重开。
- 从“最后一击”重开。

## 选项类型

### 普通选项

所有用户都能看到。

### 条件选项

满足条件后出现。

例如：
- 已解锁某个文化碎片。
- 某个变量达到要求。
- 已获得某个信物。
- 二周目才出现。

### 隐藏选项

特殊条件触发。

例如：
- 打铁花中曾生成“风火轮”。
- 剪纸中曾完成“自由落剪”。
- 糖摊中研发过节日限定糖人。

## 文化性原则

分支选项必须绑定文化点，不做无意义选择。

不建议：

```text
A. 去左边
B. 去右边
C. 留在原地
```

建议：

```text
A. 先听老匠人讲炉火规矩
B. 先检查铁勺与花棒
C. 先为今夜铁花选一个祈愿
D. 直接尝试试花
```

每个选项都应对应文化内容、技艺流程、情感方向或传承表达。

## 设计原则

- 先让用户了解非遗的来源、技艺、寓意和当代价值。
- 再让用户解锁娱乐化玩法。
- 玩法结果必须可以保存、收藏、分享。
- 每个非遗都有可复玩的衍生系统。

# 六、信物与解锁机制

## 1. 解锁逻辑

用户首次进入某个非遗主题时，不能直接玩全部高级玩法。

示例：

```text

获得“剪纸灵纹”

解锁“一物成剪”玩法

```

# 九、五个非遗衍生玩法设计

## 1. 打铁花：铁花造景

### 玩法定位

《遗境千年》中自由度最高、视觉冲击最强的核心玩法之一。

用户不是简单点击打铁花，而是像导演和匠人一样，编排一场数字打铁花表演。

### 玩法名称

**铁花造景**

### 玩法核心

用户通过 0-100 的连续参数滑杆调节打铁花过程中的关键变量，使铁花形态发生变化。

每个参数都会或大或小地影响结果。

### 可调参数

| 参数 | 范围 | 影响 |
|---|---|---|
| 击打力度 | 0-100 | 火花高度、亮度、数量、爆发范围 |
| 铁勺角度 | 0-100 | 飞行弧线、扩散方向、成花高度 |
| 击打点 | 0-100 | 火花集中度、分散程度、稳定性 |
| 勺子摆位 | 0-100 | 起始位置、构图、火瀑/火树倾向 |
| 动作幅度 | 0-100 | 匠人奔跑、旋身、跃击倾向，影响动态轨迹 |
| 击打节奏 | 0-100 | 连击密度、火花层次、节奏感 |
| 风势 | 0-100 | 火花偏移、弧线拉伸、火龙倾向 |
| 场地距离 | 0-100 | 远近透视、落点范围、画面层次 |
| 铁水温度 | 0-100 | 火花亮度、持续时间、颜色变化 |
| 安定性 | 0-100 | 形态稳定程度、散落程度 |

### 三档难度

| 难度 | 开放参数 | 系统辅助 | 核心乐趣 |
|---|---:|---|---|
| 低难度：入门试花 | 3 个 | 强辅助 | 快速出效果 |
| 中难度：匠人试艺 | 5 个 | 中辅助 | 研究参数配方 |
| 高难度：大师造景 | 10 个 | 弱辅助 | 高自由度沙盒创作 |

### 低难度

开放参数：
- 击打力度
- 铁勺角度
- 击打节奏

特点：
- 自动修正极端值。
- 自动匹配合适勺位。
- 保证生成较好的视觉效果。
- 适合首次体验。

### 中难度

开放参数：
- 击打力度
- 铁勺角度
- 击打点
- 勺子摆位
- 动作幅度

特点：
- 用户开始研究参数组合。
- 提供弧线预览和形态倾向提示。
- 适合生成稳定形态。

### 高难度

开放完整 10 个参数。

特点：
- 几乎不自动修正。
- 提供实时轨迹线、风险提示、形态相似度。
- 适合追求稀有形态和高自由度创作。

### 两种模式

#### 自由造景

用户自由调参，生成自己的铁花作品。

#### 形态挑战

系统给出目标形态，用户通过调参提高相似度。

示例：

```text
目标：生成“风火轮”
当前相似度：76%
建议：提高动作幅度，略降低铁勺角度。
```

### 可生成形态

- 火树银花
- 风火轮
- 火瀑
- 星雨
- 火龙游夜
- 满堂金花
- 双弧星桥
- 金蛇游夜

### 铁花谱

打铁花作品收藏进图鉴中的 **铁花谱**。

每个作品记录：
- 作品名
- 难度
- 参数配方
- 生成形态
- 相似度
- 评级
- 文化注释
- 生成画面
- 生成时间

示例：

```text
作品名：夜落金瀑
难度：高
形态：火瀑
评级：甲等
参数：
力度 84
角度 42
击打点 77
勺位 91
动作幅度 28
节奏 64
风势 36
温度 88
安定性 71
```

### 文化与安全表达

必须强调：

> 本互动为数字模拟体验，真实打铁花需由专业传承人与防护团队完成。

文化内容嵌入：
- 工具：铁勺、花棒、火炉。
- 技艺：力度、角度、节奏和经验。
- 场景：节庆、庙会、夜游、祈愿。
- 寓意：祈福、迎祥、驱晦、照岁。

## 2. 傩戏 / 傩舞：傩面行仪

### 玩法定位

傩戏傩舞不做简单“换舞姿”小游戏，而是做成连接现代情绪与传统傩文化的轻策略仪式玩法。

它在五个主题中的作用是：
- 强化文化厚度。
- 提供神秘、庄重、仪式化的沉浸体验。
- 通过傩面、鼓点、舞步和祈愿建立与现代生活情绪的连接。
- 形成傩面、傩纹、祈愿符等收藏内容。

### 玩法名称

**傩面行仪**

备用名称：
- 入傩问愿
- 傩舞祈仪
- 傩面驱晦

当前推荐并暂定：**傩面行仪**。

### 核心目标

用户通过选择今日心境，搭配傩面、舞步、阵位和鼓点，完成一段数字化傩舞行仪。

玩法目标不是宣称现实驱邪或转运，而是借助傩文化中的祈愿意象，完成一次数字化情绪仪式和民俗文化体验。

### 玩法流程

```text
选择今日心境
↓
选择傩面
↓
选择仪式目标
↓
编排舞步 / 阵位 / 鼓点
↓
开始行仪
↓
舞者按编排完成傩舞
↓
黑雾、杂念、晦气逐渐散去
↓
祭坛亮起
↓
生成今日傩面符
↓
收藏到图鉴
```

### 和现代生活的连接

用户可以选择今日状态：

| 今日心境 | 对应仪式目标 |
|---|---|
| 压力很大 | 驱散重压 |
| 有点迷茫 | 点明方向 |
| 最近疲惫 | 安神复气 |
| 缺少勇气 | 鼓勇前行 |
| 想要平安 | 祈愿安宁 |
| 情绪烦躁 | 平息心火 |

表达原则：

> 以傩文化中的祈愿意象，完成一次数字化情绪仪式。

避免表达为真实转运、占卜、驱邪或治愈。

### 操作维度

| 操作项 | 内容 | 影响 |
|---|---|---|
| 傩面 | 神将面、开山面、祈福面、镇邪面、丰年面等 | 仪式属性、视觉风格、收藏内容 |
| 舞姿 | 踏步、旋身、挥袖、举面、顿足 | 黑雾消散方式、动作节奏、视觉反馈 |
| 阵位 | 中央阵、环形阵、四方阵、前行阵、回旋阵 | 舞者行动路线与仪式范围 |
| 鼓点 | 慢鼓、稳鼓、急鼓、三连鼓、断续鼓 | 舞步节奏与整体氛围 |
| 道具 | 铃、鼓、旗、木剑等 | 仪式效果与视觉元素 |
| 祈愿目标 | 平安、勇气、安眠、顺遂等 | 今日傩面符文案与符纹样式 |

### 傩面类型

| 傩面类型 | 寓意 | 效果倾向 |
|---|---|---|
| 神将面 | 威严、守护 | 驱散范围大 |
| 开山面 | 开路、破障 | 清除障碍强 |
| 祈福面 | 安宁、祝愿 | 符卡效果柔和 |
| 镇邪面 | 勇气、震慑 | 黑雾消散快 |
| 丰年面 | 丰收、圆满 | 生成节庆风格符 |

### 舞步设计

用户可以排列 3-5 个动作，形成一段短行仪。

| 舞步 | 视觉效果 |
|---|---|
| 踏步 | 地面符纹亮起 |
| 旋身 | 黑雾向外散开 |
| 顿足 | 鼓点震散暗影 |
| 挥袖 | 云气展开 |
| 举面 | 傩面光纹显现 |

示例组合：

```text
踏步 → 旋身 → 顿足 → 举面
```

### 阵位设计

| 阵位 | 效果 |
|---|---|
| 中央阵 | 稳定、均衡 |
| 环形阵 | 扩散范围大 |
| 四方阵 | 守护感强 |
| 前行阵 | 破障感强 |
| 回旋阵 | 视觉最强 |

### 鼓点设计

| 鼓点 | 体验 |
|---|---|
| 慢鼓 | 庄重、安定 |
| 稳鼓 | 平衡、清晰 |
| 急鼓 | 紧张、强烈 |
| 三连鼓 | 仪式感强 |
| 断续鼓 | 神秘感强 |

### 结果生成

完成行仪后生成：

1. **行仪短动画**
   - 舞者戴上傩面。
   - 鼓点响起。
   - 舞步按顺序执行。
   - 黑雾逐渐散去。
   - 祭坛亮起。

2. **今日傩面符**
   - 傩面类型。
   - 今日心境。
   - 舞步组合。
   - 阵位。
   - 鼓点。
   - 签语。
   - 生成时间。

示例：

```text
今日傩面符：开山破雾
心境：迷茫
傩面：开山面
舞步：踏步 → 顿足 → 举面
阵位：前行阵
鼓点：三连鼓

签语：
雾重不必急行，先点一盏心中之火。
```

### 留存玩法

1. **傩面收藏**
   - 基础傩面。
   - 地域傩面。
   - 节日限定面。
   - 稀有纹样面。
   - 用户生成面。

2. **傩面符收藏**
   - 每天可生成不同“今日傩面符”。
   - 进入图鉴中的傩面符页。

3. **舞步组合图鉴**

| 组合 | 解锁仪式 |
|---|---|
| 踏步 + 顿足 + 举面 | 开山行仪 |
| 旋身 + 挥袖 + 举面 | 云开行仪 |
| 顿足 + 顿足 + 旋身 | 震鼓行仪 |
| 踏步 + 旋身 + 挥袖 | 回风行仪 |

4. **情绪陪伴**
   - 用户每天进入时可选择今日心境。
   - 系统生成不同符卡与行仪结果。

### 文化内容嵌入

文化知识分散到四个位置：

1. **选傩面时**
   - 解释傩面并非只是装饰，而承载角色、神格、情绪与仪式身份。

2. **编舞步时**
   - 解释踏步、顿足、旋身等动作在仪式感中的作用。

3. **选鼓点时**
   - 说明鼓声在傩仪中承担召集、引导、强化节奏的重要作用。

4. **图鉴中**
   - 系统沉淀“源起、流变、面具、舞步、仪式、今传”等内容。

### 避免无聊的方式

- 给用户明确目标：驱散黑雾、点亮祭坛。
- 不只是换动作，而是组合“傩面 + 阵位 + 鼓点 + 舞姿”。
- 加入现代情绪连接，如压力、迷茫、疲惫、焦躁。
- 结果可收藏为祈愿符、傩纹、短动画。
- 用傩面收藏、每日符卡和舞步组合图鉴形成复玩点。

### 注意事项

- 避免将傩文化做成廉价玄学或占卜。
- 表达为民俗祈愿、情绪陪伴和文化体验。
- 不宣称有真实驱邪、转运或治愈效果。
- 明确这是数字化体验，不等同于真实傩仪。
- 傩文化存在地域差异，后续资料需核验具体地区与代表项目。

## 4. 剪纸：一物成剪

### 玩法名称

**一物成剪**

### 玩法定位

“一物成剪”是连接现代生活与民间美术的剪纸创作系统。用户可以通过拍照、输入文字或自由创作，将生活素材转化为剪纸作品。

它在五个主题中的作用是：
- 强化生活娱乐赛道特征。
- 承接 AI 图像识别与创作转化。
- 让用户把现实生活中的物件转化为非遗风格作品。
- 形成个人剪纸册与万象集分享内容。

### 三种创作模式

```text
一物成剪
├─ 拍物成剪：拍照 / 上传 → 圈选主体 → AI 判断 → 生成剪纸
├─ 剪字成形：输入文字 → 生成剪纸字样
└─ 自由落剪：无图纸自由创作，高阶解锁
```

---

### 模式 A：拍物成剪

适合新手用户。

#### 流程

```text
拍照 / 上传图片
↓
AI 初步检测图中是否有可提取主体
↓
提示可提取对象
↓
用户圈定想要剪的主体
↓
AI 再次判断主体是否适合转剪纸
↓
生成轮廓
↓
用户选择寓意和纹样
↓
落剪生成作品
```

#### AI 判断内容

| 判断项 | 说明 |
|---|---|
| 是否有清晰主体 | 如猫、花、杯子、建筑等 |
| 背景是否复杂 | 太复杂会提示重新拍摄 |
| 轮廓是否适合剪纸 | 太碎、太细、太杂不适合 |
| 是否涉及隐私 | 人脸、证件、屏幕信息等需提醒 |
| 是否存在违规内容 | 敏感、暴力、低俗等 |

#### 提示示例

适合：

> 已识别到“花朵”轮廓，适合生成剪纸图样。

不适合：

> 当前画面主体不够清晰，建议靠近拍摄或选择背景更简单的物品。

有风险：

> 画面可能包含人像或隐私信息，建议仅用于个人图鉴，发布前需再次确认。

#### 圈选方式

第一版：
- 矩形框选。
- 手指涂抹选择。
- 点击 AI 推荐主体。

正式版：
- 自由套索。
- 智能抠图。
- 轮廓边缘微调。

### 模式 B：剪字成形

用户不拍照，直接输入文字生成剪纸字样。

#### 流程

```text
输入一个字 / 词
↓
选择字体风格
↓
选择剪纸寓意
↓
选择纹样装饰
↓
系统生成剪纸字样
↓
用户落剪
↓
收藏 / 发布
```

#### 可输入内容

- 单字：福、喜、安、愿、春、家、梦。
- 双字：平安、团圆、好运、传承。
- 短词：所愿皆安、岁岁有福。

#### 适合场景

- 新年。
- 生日。
- 节日祝福。
- 社交头像。
- 手机壁纸。
- 明信片。

文字内容也需要审核，避免不当词语、攻击性内容和敏感内容。

### 模式 C：自由落剪

高阶玩法。用户不需要图纸，自己完成一个剪纸作品。

| 纹样笔刷 | 添加云纹、花纹等 |
| 辅助网格 | 控制构图 |

#### 解锁条件

自由落剪不建议一开始开放，可以作为高阶玩法解锁。

示例条件：
- 完成 3 次拍物成剪。
- 完成 1 次剪字成形。
- 获得剪纸灵纹。

### 我的剪纸册

- 原图。

- 寓意。
- 纹样。
- 生成时间。
- 是否发布到万象集。

### 万象集发布规则

发布到万象集前需要审核。

如果作者开启“一键模仿”：
- 他人可以复用剪纸边框、纹样组合、寓意配置。
- 不复用原始照片。
- 不复用用户隐私素材。

必须明确：

> 一键模仿仅复用剪纸样式，不复用原始上传图片。

### 隐私与审核

必须提示：

> 请勿上传包含他人隐私、敏感信息或未经授权的人像照片。

审核对象：
- 上传图片。
- 生成结果。
- 作品标题。
- 作品说明。
- 万象集发布内容。

人像策略：
- 第一版支持物品、宠物、植物、建筑。
- 人像仅谨慎支持“轮廓化 / 背影 / 手势”。
- 不鼓励正脸上传。

### 技术风险

真实图片转剪纸技术成本较高。

第一版可采用：
- 上传图片。
- 显示图片预览。
- 用户矩形圈选主体。
- 模拟 AI 判断结果。
- 使用预设模板或模拟生成剪纸效果。
- 播放落剪动画。
- 收藏作品。

正式版再接入：
- 图像主体识别。
- 轮廓提取。
- 线条简化。
- 纹样融合。
- AI 生成剪纸图纸。
- 云剪纸互动。

# 十、文化内容呈现方式

## 1. 避免百科化

不能将文化内容做成长篇说明书。

应采用：
- 场景化讲述。
- 人物口述。
- 工具点击说明。
- 任务中自然解锁。
- 图鉴中沉淀。

## 2. 每个非遗的文化结构

每个非遗主题都应包含：

```text
源起
流变
技艺
寓意
今传
```

但不在主流程中一次性灌输，而是分散到互动与图鉴中。

## 3. 内容真实性原则

- 不随意编造历史事实。
- 不写未经核实的非遗级别、年份和地域归属。
- 后续正式提案中应标注资料来源。
- AI 不负责生成历史事实，只负责创作转化。

# 十一、AI 功能定位

## 1. AI 不生成历史事实

AI 不应直接编造非遗来源、传承人、年代、地域等事实性内容。

历史和文化知识应由人工整理，并基于公开权威资料核实。

## 2. AI 主要负责创作转化

AI 可用于：
- 图片转剪纸风格。
- 生成皮影小剧本。
- 生成守护卡文案。
- 生成非遗作品海报。
- 辅助用户把生活素材转化为非遗风格作品。

## 3. 内容审核

特别是皮影剧本、用户输入、图片上传等功能，需要内容审核机制。
