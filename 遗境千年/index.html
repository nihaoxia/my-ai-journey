项目定位

《遗境千年》不是非遗百科，也不是单纯展览，而是一个面向大众的生活娱乐型非遗数字体验产品。

核心一句话

用户打开手机，进入一张古今共屏的数字长卷；在五类非遗中体验分支剧情、做出选择、收集结局，再解锁深度玩法，把非遗转化为自己的作品并发布到万象集。

赛道判断

偏生活娱乐：可看、可玩、可创作、可收藏、可分享、可复玩。文化内容通过剧情、工具、流程和作品沉淀自然进入体验。

体验闭环

首页五艺入口
从古今共屏长卷进入岁时民俗、民俗仪式、表演叙事、民间美术、饮食游艺。
剧情分支体验
在剧情中做选择，体验工具、流程、技艺、寓意与传承。
结局与信物
不同选项导向不同结局，结局入册，信物解锁深度玩法。
创作与分享
造景、行仪、影戏、剪纸、经营生成作品，收藏图鉴或发布万象集。

主玩法：多分支剧情体验

点击任意非遗后，用户先进入剧情篇章。剧情选项影响后续节点、文化碎片、体验方式、信物属性、深度玩法素材与最终结局。

Core Gameplay

剧情选择，不是跳过文化；而是把文化放进选择里。

首次进入需要完整体验剧情；二次进入可跳过已看剧情，直接跳至选择节点，或从关键节点重开以收集不同结局。

多节点选择结局收集故事回溯信物解锁
开场节点 场景、人物、文化问题出现。
选择节点 每个节点 3～5 个选项。
非遗体验节点 工具、技艺、流程和寓意进入互动。
结局节点 5～8 个结局进入结局图鉴。
深度玩法 信物解锁铁花造景、一物成剪等复玩系统。

剧情变量

技艺理解、情感倾向、传承倾向、创新倾向共同影响结局。

条件选项

二周目、已解锁文化碎片、已获得信物或特定作品会触发隐藏分支。

文化绑定

选项对应工具、技法、寓意、人物关系或传承表达，避免无意义选择。

节点回溯

用户可从关键节点重开，收集不同结局，不必反复看完整开场。

五艺与深度玩法

五个入口对应五个大类。剧情篇章负责文化与结局，深度玩法负责复玩、创作、经营与社区传播。

火

岁时民俗 · 打铁花

剧情后获得焰火令，解锁“铁花造景”：0-100 连续参数调节力度、角度、击打点、勺位、动作、节奏、风势等，生成火树银花、风火轮、火瀑等形态。

傩

民俗仪式 · 傩戏傩舞

剧情后获得傩面符，解锁“傩面行仪”：选择今日心境、傩面、舞步、阵位与鼓点，生成数字化行仪和今日傩面符。

影

表演叙事 · 皮影戏

剧情后获得影戏签，解锁“一幕生影 · 影戏工坊”：AI 编剧或手动导演，选择幕数、角色、场景、动作和台词，创作皮影作品。

剪

民间美术 · 剪纸

剧情后获得剪纸灵纹，解锁“一物成剪”：拍物成剪、剪字成形、自由落剪三种模式，把生活素材转化为剪纸作品。

糖

饮食游艺 · 糖人糖画

剧情后获得糖画签，解锁“糖摊小铺”：经营养成、搭配研发糖人、完成订单、升级摊位，节日解锁限定样式。

图鉴与万象集

图鉴是私人收藏，万象集是公共分享。作品默认进入个人图鉴，用户选择发布后，经审核进入万象集。

我的图鉴

  • 结局图鉴：记录每个非遗剧情的不同结局。
  • 信物收藏：焰火令、傩面符、影戏签、剪纸灵纹、糖画签。
  • 作品集：铁花谱、傩面符、影戏集、剪纸册、糖画谱。

万象集

全局作品分享平台，支持打铁花、剪纸、皮影、傩面符、糖画与后续陶瓷、刺绣等分类。发布时作者可选择是否允许他人一键模仿；若允许，再创作作品自动标注灵感来源。

技术组合：A + B + 轻量 C

本提案页选择 A、B、轻量 C 的组合：用 CSS 构建响应式视觉系统，用原生滚动观察实现序列动画，用 Canvas 粒子营造火星与数字光流。

最终用户体验

用户滚动页面时，内容以交错节奏进入视野；背景火星粒子持续漂浮，并随指针产生轻微引力；首页“古今共屏”以非对称布局展现古代百艺与现代平台的自然融合。

A
现代 CSS 视觉系统
变量、clamp、Grid、Flex、伪元素、混合模式、响应式令牌。
B
高级动效叙事
不依赖 UI 框架，使用 Intersection Observer 实现 Stagger 入场；以原生滚动与 CSS 过渡模拟滚动叙事。
C
轻量粒子世界
原生 Canvas 粒子系统模拟火星、糖线与数字光点，避免引入大型 3D 库造成性能负担。

代码约束落实

  • 零外部 UI 依赖：未引入 Bootstrap、Tailwind、Ant Design 等框架。
  • 语义化结构：使用 header、nav、main、section、article、footer。
  • 可访问性：提供跳转正文链接、ARIA 标签、导航语义。
  • 性能降级：使用 prefers-reduced-motion 关闭粒子与动效。
  • 渐进增强：即使禁用动画，内容仍完整可读。

开发计划

第一版目标是做出能够清楚展示主线、视觉和核心玩法的高质量 Demo，而不是一次性实现完整商业社区。

阶段一：提案与内容

重写新版提案、整理五艺资料、确定每个非遗第一版剧情主题和结局数量。

阶段二：视觉原型

制作“百艺入屏”分镜、古今共屏首页、五艺入口、图鉴与万象集核心页面。

阶段三：玩法 Demo

优先实现打铁花参数化造景、剪纸一物成剪原型、皮影工坊简化演出。

阶段四：答辩展示

准备演示路线、技术架构、文化价值、创新价值、风险与版权审核说明。
